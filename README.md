# notesd on Railway

notesd — self-hosted Markdown notes with offline Android/iOS/Mac apps, sync, search and passkeys. Deploy on Railway with one click.

This repository packages the official [notesd](https://github.com/cassiozen/notesd) image (`ghcr.io/cassiozen/notesd:1.5.1`, MIT) for Railway. Independent community packaging, not affiliated with the notesd project.
